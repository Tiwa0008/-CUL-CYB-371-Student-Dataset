# Fictional Student Dataset

**Course:** CUL-CYB 371 – Data Mining and Data Warehousing  
**Assignment:** Assignment Two

## Description
This project contains a fictional dataset of 20 students. It includes the five required fields:

1. Student ID
2. Department
3. Level
4. Attendance Percentage
5. Average Examination Score

All student records are fictional and are provided for academic practice only.

## Files
- `create_dataset.py` – Python program used to create the dataset.
- `student_dataset.csv` – Dataset generated by the Python program.

## How to run
1. Make sure Python 3 is installed.
2. Open a terminal in this project folder.
3. Run: `python create_dataset.py`
4. The program creates `student_dataset.csv`.

## Data note
Attendance percentages and examination scores are recorded on a scale from 0 to 100.
